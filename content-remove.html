What gets removed

C2PA / Content Credentials (JUMBF manifests), EXIF, XMP, IPTC-IIM, Photoshop resource blocks, MakerNotes, GPS, thumbnails, tEXt/iTXt comments, ID3 tags, QuickTime udta atoms and iTunes meta atoms.

What stays intact

Every pixel and every audio-video sample. Images are not re-encoded, so there is no generational quality loss. Video is patched in place — byte offsets never move, so the file plays exactly as before.

Worth knowing

Metadata is not the only trace. Sensor noise patterns, encoder fingerprints and visible content in the frame itself survive any metadata strip. This tool handles the metadata layer, nothing beyond it.

NULLFRAME All processing happens in your browser. Your files never leave your device.
